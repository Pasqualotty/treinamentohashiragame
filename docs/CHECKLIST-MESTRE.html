Produto 1. Visão do produto

Jogo 2D pixelado de fases (side-view / run de estágios), tema Demon Slayer, Android, uso pessoal (família e amigos).

Pitch (1 frase)

Avance por fases matando onis, encha a respiração pro especial, junte moedas, melhore o caçador e enfrente o chefão do mundo — desbloqueando Hashiras pelo caminho.

Pilares

① Combate de espada legível (3 ataques + especial)
② Progressão por moedas/upgrades
③ Mundos com chefão
④ Elenco reconhecível (pixel)

Loop principal (core loop)

PassoO que o jogador fazRecompensa
1. Hub / Mapa do mundoEscolhe fase ou loja—
2. FaseAnda, ataca onis, evita danoMoedas (+10 por oni fraco)
3. Fim da faseChega no portal / mata o últimoDesbloqueia próxima fase
4. LojaGasta moedasMais HP, dano, etc.
5. Chefão do mundoÚltima fase do mundoAvança mundo + (opcional) personagem
  • Hub → mapa → fase → moedas → loja. JOGAR abre o mapa (não a fase direto).
  • Paisagem (celular deitado) — GDD §1.
  • 1280×720 em project.godot · stretch canvas_items · filter off.

Workshop 2. Decisões a fechar antes de codar pesado

Fonte canônica: docs/GDD-DECISOES.md. Itens abertos ainda bloqueiam pouco o slice — podem fechar no playtest.

Workshop base fechado (2026-08-03). Restam só nomes de skills, lista exata dos 4 upgrades, rewards de elite/boss e regra fina de moeda na morte.

2.1 Câmera e gênero 2D

  • Side-scroller linear por fase — GDD §1.
  • Sim, 1 pulo (sem double jump no MVP). + Dash com cooldown (botão Avançar).
  • Fonte: docs/GDD-DECISOES.md §4. InputMap alvo: move_*, advance, jump, attack_basic, skill_1, skill_2, ultimate, pause.

2.2 Combate

  • Modelo fechado: 1 atk básico (combo curto) + skill_1 + skill_2 + ultimate (não é mais trinca leve/pesado/estocada). Nomes ainda abertos no GDD §9.
  • Botões independentes (básico / H1 / H2 / ultimate). Básico pode ter combo curto interno; skills e ultimate não são “3 ataques soltos”.
  • Enche com hits. Tempo sozinho não enche. Dano esvaziar = opcional depois (default MVP: não).
  • Consome barra (zera). Multi-hit/i-frames = balance no slice. Botão só habilitado com barra full.
  • MVP: dash sem i-frames (pode virar upgrade). Não há “esquiva” separada do dash.

2.3 Economia

  • Sugestão: HP · dano básico · ganho de respiração · cooldown do dash. Ainda aberto no GDD §9.
  • Autoload Game já grava coins_banked em user://save.json.
  • Default técnico: moedas da fase no contador run; bank ao completar; morte → perde só a run. Código já tem bank_run_coins / lose_run_coins. Confirmar no playtest.

2.4 Progressão de personagens

  • MVP: só Tanjiro. Proposta W1 → Zenitsu etc. na seção 4.
  • Sugestão GDD: globais no MVP.

2.5 Escopo do primeiro entregável

  • GDD §7 — congelado. Combate = atk básico + 2 skills + ultimate + dash + pulo.
