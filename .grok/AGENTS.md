# Treinamento Hashira — regras agenticas do projeto

## Skills obrigatórias

Ao trabalhar neste repositório:

| Domínio | Skill (carregar / seguir) |
|---------|---------------------------|
| Game design, UI hub, controles, loop, mapa, feel | `pasqualotti-game-design` (`~/.grok/skills` ou `.grok/skills`) |
| Arte Imagine, sprites, key art, botões, chroma, packs | `grok-imagine-game-assets` |

**Sem pular** a skill de arte em qualquer geração de imagem de jogo.  
**Sem pular** a skill de design em mudanças de hub/flow/controles.
